# Paradise Nursery 🌱

Paradise Nursery is a React-based shopping cart application for an online plant shop offering a variety of house plants.

The application provides an interactive shopping experience where users can browse plants organized into different categories, view plant information including images, descriptions, and prices, and add their preferred plants to a shopping cart.

Users can manage their cart by increasing or decreasing plant quantities, deleting items, and viewing the cost of individual plant types as well as the overall cart total. The application also includes navigation between the landing page, product listing page, and shopping cart, along with **Continue Shopping** and **Checkout** options.

This project applies React development concepts and dynamic functionality to create a practical e-commerce-style frontend prototype.
